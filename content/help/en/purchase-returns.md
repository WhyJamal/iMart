# Supplier Returns

Returning a product to a supplier that was previously received via a [Purchases](/help/purchases) document is done in this section.

## Creating a return

The search is done by the purchase document number. For each product in the found purchase, the quantity bought, returnable, and being returned is shown.

## Reason and refund

A reason for the return is entered, and a refund method (cash/card/QR) is selected.

## Result

Warehouse stock decreases by the returned quantity, and the counterparty's debt or refund amount is updated accordingly.
