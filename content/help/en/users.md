# Users

Staff members and their access rights to the system are managed in this section.

## Creating a user

When a user is created, a name, login credentials, role (e.g. Admin, Manager, Cashier), [location](/help/points), and [work schedule](/help/work-schedules) are set.

## Roles

Each role has access to specific sections — for example, a cashier only works with [POS](/help/pos), while an Admin can also manage settings.

## List

The list shows the user's name, role, location, and status — editing or toggling activity is done from here.
