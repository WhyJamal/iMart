# Отчёт по долгам

Сводный обзор всех долгов — в двух направлениях: должны нам и мы должны поставщикам.

## Должны нам

Список клиентов с долгом из раздела [Клиенты (должники)](/help/debtors), с указанием общей суммы.

## Мы должны

Список поставщиков с долгом из числа [Контрагентов](/help/contragents), с указанием общей суммы.

Оба списка отсортированы от наибольшего долга к наименьшему.
