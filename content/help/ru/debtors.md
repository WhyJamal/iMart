# Клиенты (должники)

Этот раздел используется для продажи клиентам в долг и отслеживания их текущей задолженности.

## Как возникает долг

При выборе способа оплаты «В долг» на кассе из списка указывается соответствующий клиент (должник). Полная сумма продажи записывается на долг этого клиента.

## Список должников

На странице «Клиенты (должники)» отображаются все должники и их текущая сумма задолженности. С карточки каждого должника можно открыть полную историю платежей.

## Приём оплаты

Выбрав должника, через окно «Приём оплаты» вводится частичная или полная сумма. Введённая сумма автоматически вычитается из общей задолженности должника.

## Оплата из списка контрагентов

Частичная оплата поставщикам ([контрагентам](/help/contragents)) выполняется аналогично — через соответствующую строку в списке контрагентов.

## Отчёт по долгам

Сводная информация по всем долгам доступна в разделе *Отчёты → [Отчёт по долгам](/help/debt-report)*.
