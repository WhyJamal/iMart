# О Vol-Mart

**Vol-Mart** — полноценная система управления магазином (ERP): продажи, склад, касса, сотрудники и отчёты — всё в одном месте.

## Что умеет?

- **Касса (POS)** — продажа товаров через сканирование или поиск, разные способы оплаты (наличные, карта, в долг), печать чека.
- **Склад** — приход товаров (документ «Kirim», включая массовую загрузку через Excel), остатки по складам/ячейкам, перемещения, списания.
- **Долги** — продажа в долг клиентам, учёт платежей по долгам, частичная оплата поставщикам.
- **Акции** — временные скидки на товары.
- **Сотрудники** — график работы, табель, расчёт зарплаты.
- **Отчёты** — материальный отчёт, отчёт по продажам, прибыль и убытки (P&L), отчёт по долгам — всё с фильтром по точке (филиалу).
- **Настройки** — режим ценообразования (по номенклатуре или по средней себестоимости), процент налога, шаблоны чеков, тема (цвет/тёмный режим).

## Для кого?

Для торговых организаций с одной или несколькими точками продаж — каждый сотрудник получает доступ к нужным разделам согласно своей роли (Владелец, Админ, Менеджер, Кассир и т.д.).
