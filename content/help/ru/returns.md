# Возвраты продаж

Оформление товара, возвращённого клиентом, выполняется в этом разделе.

## Новый возврат

Поиск выполняется по номеру продажи. Для каждого товара в найденной продаже отображается проданное, доступное к возврату количество, возвращаемое количество и цена.

## Причина и возврат средств

Указывается причина возврата, выбирается способ возврата денег (наличные/карта/QR).

## Результат

На возвращённое количество увеличивается остаток склада, клиенту возвращается соответствующая сумма.
