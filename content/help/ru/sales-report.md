# Отчёт по продажам

Сводный отчёт по [продажам](/help/sales) в разрезе товаров — проданное количество, выручка и прибыль по каждому товару.

## Фильтры

Можно фильтровать по диапазону дат, точке и категории.

## Таблица

В каждой строке отображаются товар, категория, количество, единица, средняя цена, выручка, себестоимость, прибыль и маржа (в процентах); внизу — итоговые значения.
