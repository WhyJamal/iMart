# Приход (Склад)

Документ «Приход» используется для оприходования товаров из существующего [каталога](/help/items) — остаток по соответствующей ячейке [склада](/help/warehouses) увеличивается.

## Создание документа

При создании документа выбираются точка, склад и ячейка — эти значения по умолчанию применяются ко всем строкам. При необходимости ячейку можно изменить отдельно для каждой строки.

## Добавление строки

В каждой строке выбирается товар из существующего каталога — новый товар через этот документ не создаётся. Указывается количество; поле цены (себестоимости) необязательно — если оставить пустым, используется стандартная цена товара.

## Загрузка через Excel

Вместо ручного ввода большого количества товаров можно скачать готовый шаблон таблицы, заполнить его и загрузить через «Загрузить из Excel». Товары сопоставляются сначала по коду, при отсутствии — по названию. О строках, не найденных в каталоге, выводится отдельное уведомление, остальные строки загружаются без проблем.

## Удаление документа

При удалении документа указанные в нём количества автоматически вычитаются из соответствующего остатка склада.
